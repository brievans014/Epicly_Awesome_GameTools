# Epicly_Awesome_GameTools
Top 10 awesome Game Dev

#Aseprite  -

Aseprite is a 2d pixel art / animation program that works on almost every computer. (Windows, Mac, Linux) Considered an industry standard since so many people use it. Generally considered easy to learn as it has a user friendly interface. It’s $20 on steam but you can also get the source code and compile the program off of github to use it. 

Has a bunch of pretty cool built in features (though I think most art programs nowadays have pretty similar features) like their pixel perfect mode which lets you get rid of ugly 90 degree angles without erasing all the pixels you don't like. 

#Krita - 

Krita is a free open source digital art and animation program. I used this one in the past a lot, a pretty standard art program. Similar features to Aseprite and is pretty easy to get a hang of. Used a lot mostly because it’s free and it has good features. Though it is very limiting once you know what you’re doing with it. Programs like Adobe and Procreate surpass Krita by miles.

#GIMP - 

Gimp is a free open source image editing program available for Mac Windows and Linux. GIMP is widely considered to be a budget friendly version of photoshop. While it has good features (such as their layer support) it also has its downsides. GIMP has a cluttered interface which makes it hard for beginners to learn. It’s also considered to be outdated, and runs rather poorly on modern machines.

#Visual Studio Code -

VS Code is a free open source code editor. Easy to learn / use on a day to day basis. Less popular to use in Game Development due to basically being a code editor and not a full fledged IDE. Leading to actual IDE’s such as Visual Studio, being more popular. 

#Gamemaker -

Gamemaker is a game engine designed primarily for making 2D video games. Fantastic for making a typical Earthbound like JRPG. One of the major downsides (or upsides depending on perspective) is that Gamemaker features its own coding language. Which makes it difficult for beginner developers because not only do they have to learn game development, but they also have to learn an entirely new language. 

#Unity - 

Unity is a software used to make 2D, 3D, Virtual Reality, and Augmented Reality video games. It’s super popular and is considered an industry standard. Unity has many amazing features such as their Cross Platform support which helps developers export their games easily onto multiple platforms and their asset store which features countless readily available assets for beginner developers to use. One of the major disadvantages is the amount of storage Unity takes as well as the amount of RAM it uses. 

#RPG Maker - 

A series of software programs designed to make 2D role-playing games easily so beginner developers can make games without much knowledge. Has a bunch of built in assets and tutorials to make things as accessible as possible. Often very affordable because of frequent sales. Unfortunately the programs are very limited and can't make much else besides typical RPG’s.

#FL Studio - 

FL Studio is a popular Digital- Audio-Workstation(DAW) , a program used to compose, arrange, record, edit and mix professional music and audio. Considered an Industry Standard due to its great selection of instruments and mixing. One of the biggest drawbacks is how difficult it is for beginners to learn FL Studio as its program is rather clunky and cluttered. 

#Procreate - 

Procreate is an award winning digital art app that is widely used by professionals and beginners everyday. It has a large brush library for endless customization, many amazing tools to make artists' lives easier, and has a one time purchase of $12.99 making it rather affordable. It’s biggest con? It’s designed only for Apple products. Meaning you have to use either an Ipad or Iphone to use their program. 

#Godot - 

Godot is a free, open-source game engine designed to make 2D, 3D, and extended reality games. Godot’s greatest strength is that it’s free, small and fast to use. Unfortunately because Godot is less known in the industry compared to Unity or Unreal, it has some major disadvantages. It has less learning resources making it difficult for beginners to learn the engine, and it is harder for developers to land jobs after working on projects with Godot because it is less known than some other popular engines.
